# Mandala releases

Official installer downloads for [Mandala](https://mandala.pub).
This repository contains installers, checksums and release notes only. The application source repository remains private.

## macOS preview

[Download for Apple Silicon](https://github.com/maktub-ai/mandala-releases/releases/download/v0.1.2-preview.20261108/Mandala-0.1.2-preview.20261108-mac-arm64.dmg)

[Release notes and SHA256 checksums](https://github.com/maktub-ai/mandala-releases/releases/tag/v0.1.2-preview.20261108)

The current preview is ad-hoc signed and not Apple-notarized. Windows and Intel Mac installers are not currently published. Stop the runtime before replacing an existing installation.

New versions appear under [Releases](https://github.com/maktub-ai/mandala-releases/releases). Preview versions are explicitly labeled.
